# v0.3 Hardware-Alpha Release Readiness

## Purpose

This document prepares AssureLoop for a v0.3 hardware-alpha release focused on
release assurance for one physical Zephyr board: ST NUCLEO-H563ZI.

v0.3 is not production OTA, not a production secure-boot implementation, not a
cloud service, and not a safety or cybersecurity certification claim.

## Supported Hardware

- Board: ST NUCLEO-H563ZI
- Zephyr board target: `nucleo_h563zi`
- Connection: top ST-LINK USB-C port
- Serial console observed during validation: COM4 at 115200 baud
- Programmer: STM32CubeProgrammer v2.22.0
- Zephyr SDK path used during validation: `D:\zephyr-sdk`

No broad board support is claimed for v0.3.

## Non-Production Limitations

- Development signing keys are generated locally under ignored `keys/` paths.
- Images are staged by direct flashing, not by a real OTA transport.
- The workflow has no cloud service, fleet policy, or remote update channel.
- Downgrade validation uses MCUboot image-version downgrade prevention, not
  hardware-backed rollback counters or fuses.
- Serial evidence is captured manually.
- Only ST NUCLEO-H563ZI is hardware-validated.
- The evidence is suitable for hardware-alpha evaluation, not production
  certification.

## Completed Hardware Proof Points

- Basic Zephyr build, flash, and COM4 serial logging.
- Board-specific signed image evidence and update package generation.
- MCUboot bootloader execution and signed primary application chainload.
- Local direct-flash secondary-slot staging at `0x08102000`.
- MCUboot swap-using-offset update from secondary to primary.
- Confirmed update persistence after reset.
- Unconfirmed test update rollback after reset.
- Tampered secondary image rejection.
- Lower-version secondary image rejection by MCUboot downgrade prevention.

## Reproduce

Host tests:

```powershell
.\scripts\test-tools.ps1
```

Full simulator flow:

```powershell
.\scripts\full-demo.ps1 -Python py
```

Basic board build:

```powershell
.\scripts\hardware-build-nucleo-h563zi.ps1 -Python py
```

Board-specific signed evidence:

```powershell
.\scripts\signed-image-demo-nucleo-h563zi.ps1 -Python py
```

MCUboot boot verification:

```powershell
.\scripts\mcuboot-verify-nucleo-h563zi.ps1 -Python py
```

Lifecycle build-only check:

```powershell
.\scripts\mcuboot-update-lifecycle-nucleo-h563zi.ps1 -Python py
```

Hardware lifecycle negative checks:

```powershell
.\scripts\mcuboot-update-lifecycle-nucleo-h563zi.ps1 -Python py -TamperUpdate -EraseBeforeFlash -Flash
.\scripts\mcuboot-update-lifecycle-nucleo-h563zi.ps1 -Python py -DowngradeUpdate -EraseBeforeFlash -Flash
```

Git Bash equivalents:

```bash
PYTHON=py bash scripts/full-demo.sh
PYTHON=py bash scripts/mcuboot-update-lifecycle-nucleo-h563zi.sh --tamper-update --erase-before-flash --flash
PYTHON=py bash scripts/mcuboot-update-lifecycle-nucleo-h563zi.sh --downgrade-update --erase-before-flash --flash
```

## What Not To Claim

Do not claim:

- production OTA,
- production secure boot,
- hardware-backed key custody,
- certified safety or cybersecurity compliance,
- broad hardware support,
- cloud update management,
- protection against every possible image corruption pattern.

v0.3 demonstrates a credible local hardware-alpha release assurance workflow
for one board using development keys and direct flashing.
