# ADR 0002: Keep the core open-source

Date: 2026-06-09

## Status

Accepted for initial development.

## Decision

The initial AssureLoop core is Apache-2.0 and includes:

- Zephyr app skeleton,
- release manifest tooling,
- verification tooling,
- evidence bundle tooling,
- public docs and testing guides.

## Commercial boundary later

Potential paid layers later may include:

- supported LTS branches,
- hardware enablement,
- customer-specific validation,
- certification evidence packs,
- managed vulnerability response,
- advanced tracing/profiling dashboards.

## Guardrail

The public repo must be useful without a commercial license.
